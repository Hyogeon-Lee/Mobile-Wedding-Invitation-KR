# 차분한 자연광 디자인

작업 브랜치: `codex/soft-natural-design`

## 방향과 계획

서늘한 아이보리·연한 초록과 명조 서체를 유지하면서 사진, 글, 섹션 사이의 경계를 부드럽게 연결한다. 오프닝은 사용자가 선택한 어두운 사진과 흰 손글씨로 구성하고, 밝은 본문으로 이어지게 한다. 섹션 순서는 유지한다.

1. 공개 디자인 스킬과 참고 청첩장의 오프닝을 검토하고 적용할 원칙을 정한다.
2. 글의 위계, 사진 가장자리, 자연광 배경, 섹션 이동을 조정한다.
3. 갤러리는 처음 5장만 표시하고 나머지는 펼쳐서 볼 수 있게 한다.
4. 모바일 360px·390px와 데스크톱에서 렌더링, 사진 확대, 펼치기·접기, 섹션 이동을 검증한다.
5. 빌드·lint·테스트를 통과시킨 뒤 `.claude`의 주석·커밋 규칙에 맞춰 커밋한다.

## 참고 자료와 적용 판단

- [awesome-design-skills](https://github.com/bergside/awesome-design-skills)의 [editorial](https://github.com/bergside/awesome-design-skills/blob/main/skills/editorial/SKILL.md), [spacious](https://github.com/bergside/awesome-design-skills/blob/main/skills/spacious/SKILL.md), [refined](https://github.com/bergside/awesome-design-skills/blob/main/skills/refined/SKILL.md), minimal을 검토했다. 명확한 서체 위계, 충분한 여백, 절제된 장식, 읽기 쉬운 대비를 적용했다. 저장소 고유의 색과 폰트는 유지했다.
- [Emil Design Engineering](https://github.com/emilkowalski/skills/blob/main/skills/emil-design-eng/SKILL.md)의 목적이 있는 모션, 일관된 감속, 네이티브 터치 스크롤, 모션 감소 원칙을 적용했다.
- [참고 청첩장 오프닝](https://github.com/sooftware/our-wedding-invitation/blob/main/static/js/animations.js)을 검토했다. 전체 사진 위에 세 줄 손글씨가 순서대로 써지고 밑줄을 그린 뒤 표지로 사라지는 흐름을 벤치마킹했다.
- 손글씨는 [Vara의 Parisienne 스트로크 데이터](https://github.com/akzhy/Vara/blob/master/fonts/Parisienne/Parisienne.json)에서 필요한 문구만 정적 경로로 배치했다. 기존 Motion으로 재생하므로 Vara 런타임이나 외부 폰트 요청을 추가하지 않는다. 출처와 MIT·OFL 고지는 [opening-lettering.txt](../public/licenses/opening-lettering.txt)에 포함했다.
- 참고 청첩장의 코드나 사진은 복사하지 않았다. `.claude/skills/lean-comments/SKILL.md`와 `.claude/skills/git-commit/SKILL.md`를 읽고 변경 부분의 주석 및 커밋에 적용했다.

## 최종 변경

| 요소 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 오프닝 | 바로 표지 표시 | 어두운 전체 사진, 흰 손글씨 3줄과 밑줄, 밝은 표지로 페이드 |
| 표지·사진 | 흰 테두리, 그림자, 뚜렷한 모서리 | 이미지 가장자리에 정적 페더 마스크, 약한 빛 이동 |
| 갤러리 | 처음 9장, 기울어진 프레임 | 처음 5장, 정돈된 2열·전체 폭 배치, 더 보기·접기 |
| FAMILY | 초록색 얼룩처럼 보이는 고정 배경과 세로 카드 | 넓은 선형 자연광, 36초·48초 단방향 변화, 왼쪽 신랑 측·오른쪽 신부 측의 두 열 |
| 본문 | 가는 명조와 장식 구분자 | 명조 400, 구분자 제거, 제목과 본문의 일관된 위계 |
| 섹션 이동 | 서로 다른 스크롤 방식 | Lenis에서 0.9초 감속을 공유, 터치는 네이티브 유지 |
| 등장 효과 | 비교적 큰 이동, 긴 블록 전체 등장 | 6px 이동, 화면 진입 직전 등장, 사진별 짧은 페이드 |
| 잎·꽃잎 | 일부 섹션에 집중 | 표지 3개, 나머지 섹션별 2개, 32.4~54초의 느린 낙하 |
| 네이버 지도 | 임시 좌표 기반 앱 이동 | 사용자가 제공한 장소 공유 링크로 이동 |

오프닝의 사진은 1.2초 동안 들어온다. 손글씨는 0.6초 뒤 시작해 한 줄씩 0.7초 동안 그려진다. 밑줄은 2.7초에 시작한다. 3.4초부터 0.8초 동안 사라진다. `바로 보기`로 건너뛸 수 있고 본문 스크롤을 잠그지 않는다. 모션 감소를 설정했거나 특정 본문 섹션으로 직접 들어오면 오프닝을 생략한다.

네이버 지도는 `event.naverMapUrl`에 [제공된 링크](https://naver.me/5uIYZdsZ)를 저장했다. 브라우저에서 노블발렌티 삼성점, 서울 강남구 봉은사로 637로 연결됨을 확인했다. 이 필드를 비우면 기존 좌표 기반 앱 이동과 주소 검색이 유지된다. 목적지 좌표는 네이버 장소의 길찾기 링크에서 확인한 위도 37.5153463, 경도 127.0648868로 카카오맵·티맵에 함께 적용했다.

## 확정 내용과 사진

- 이효건·박민경, 2027년 6월 27일 일요일 오후 1시. 단독 예식이므로 장소는 홀 이름 없이 노블발렌티 삼성으로 표시한다.
- 신랑 측 이용희·조경숙, 신부 측 박재영·김금란. 연락처 버튼·시트와 전화번호 환경 변수는 제거했다.
- 제공된 사진 10장은 긴 변 최대 1600px의 WebP로 변환하고 EXIF를 제거했다. 원본 파일은 수정하지 않았다. 표지를 포함한 이미지 11개는 합계 약 1.35MB다.
- 표지는 밝은 창가 사진 `LSJ_3996.JPG`를 1200×1600으로 잘라 사용한다. 같은 사진을 오프닝에서는 어둡게 덮어 흰 손글씨와 대비시킨다.
- 갤러리 01~10의 원본 순서는 `0XE50472.jpg`, `IMG_0163.jpg`, `LSJ_2579.JPG`, `LSJ_3767.JPG`, `LSJ_3836.JPG`, `DSCF7374.JPG`, `LSJ_3996.JPG`, `LSJ_4561.JPG`, `LSJ_4454.JPG`, `KMW_0384.jpg`다. 처음 5장으로 두 사람의 초상과 따뜻한 실내 사진을 보여주고, 펼치면 야외·노을·소품 사진으로 이어진다.
- 사진은 원본 비율을 유지한다. 가로 사진은 위치와 관계없이 두 열을 모두 사용하므로 사진을 추가할 때 고정된 세 번째 자리 규칙을 맞출 필요가 없다.
- 공유 이미지와 메타데이터도 확정 이름·날짜로 갱신했다.

## 검증 기준

- 일반 모바일 첫 화면에서 표지의 사진·이름·일시·스크롤 안내가 잘리지 않는다.
- 장식은 입력을 가로채지 않고 보조 기술에서 숨긴다. 사진의 포커스 테두리는 마스크 밖에 남긴다.
- 지속되는 배경 효과는 transform·opacity만 움직이고 화면 밖에서 멈춘다. 모션 감소에서는 정지한다.
- 손글씨는 작은 SVG 경로 4개를 한 번 그리는 예외다. 연속 배경 효과와 분리해 비용을 제한한다.
- 처음 사진 5장, 펼친 사진 10장, 접은 사진 5장과 전체 사진 확대를 확인한다.
- 기능 테스트, lint, 프로덕션 빌드가 통과해야 한다.

## 로컬 확인

`npm run dev -- --host 127.0.0.1 --port 5173`

[로컬 미리보기](http://127.0.0.1:5173/)를 새로 고치면 오프닝이 재생된다. 캡처는 Git에서 제외되는 `qa/daylight/`에 저장한다.

## 디자인 단계 검증 결과 (사진 교체 전)

- `npm run build`, `npm run lint`, `npm test` 통과. 테스트 파일 20개, 테스트 159개. 제거한 사진 기울기 함수의 테스트도 함께 제거했다.
- Chromium CSS viewport 360×640, 390×844, 1280×900에서 가로 넘침 없음. 360×640의 19px 큰 글씨에서도 표지 스크롤 버튼이 첫 화면 안에 표시됨.
- 사진 5장으로 시작하고 펼치면 12장, 접으면 5장임을 확인했다. 펼친 6번 사진의 확대 화면은 `6 / 12`로 표시되며 정상적으로 닫힌다.
- 표지의 다음 내용 이동과 푸터의 맨 위 이동을 확인했다. 손글씨 완성 장면, 자동 종료, 바로 보기, 본문 직접 링크의 오프닝 생략을 확인했다.
- FAMILY 배경의 실제 CSS 주기는 36초·48초다. 360px 큰 글씨에서도 왼쪽 신랑 측·오른쪽 신부 측이 두 열로 표시되며 가로 넘침이 없다. 연락하기 시트도 열린다.
- DOM에서 표지의 잎·꽃잎 3개, 나머지 10개 섹션의 잎·꽃잎 각 2개를 확인했다. FAMILY 낙하 주기는 36.864초·46.836초로 표시된다.
- 네이버지도 버튼의 실제 링크가 사용자가 제공한 공유 URL과 일치함을 확인했다.
- 최종 새로 고침 이후 수집된 브라우저 오류·경고 없음.
- 모션 감소와 고대비 처리는 소스의 미디어 쿼리, Lenis 옵션, 장식 접근성 테스트로 확인했다. 실제 OS 설정 전환과 iOS·Android 기기 검증은 수행하지 않았다.

## 확정 내용 검증 결과

- `npm run build`, `npm run lint`, `npm test` 통과. 테스트 파일 20개, 테스트 153개. 삭제한 연락처·고정 사진 배치 테스트를 정리하고 지도 링크 검증 테스트를 추가했다.
- CSS viewport 360×640, 390×844에서 가로 넘침 없이 신랑·신부와 부모님 이름이 두 열로 표시된다. 연락하기 버튼은 없고, 표지와 달력에는 2027년 6월 27일 일요일 오후 1시가 표시된다.
- 실제 사진으로 갤러리 5장, 펼친 뒤 10장, 접은 뒤 5장을 확인했다. 6번 사진의 확대 화면은 `6 / 10`으로 표시되고 닫힌다. 가로 사진은 두 열 전체를 사용한다.
- 실제 표지 사진과 어두운 오프닝 위 흰 손글씨의 대비를 확인했다. 공유 이미지는 1200×630이다. 이미지 11개에 EXIF가 남아 있지 않음을 검사했다.
- 지하철 검색 링크는 봉은사역4번출구, 버스 검색 링크는 봉은사역3번출구·삼성1파출소(23192)를 결과에 표시한다. 주차 링크는 안내를 확인한 네이버 장소 정보로 연결한다.
- 브라우저에서 수집된 오류·경고 없음. 실제 iOS·Android 앱 실행은 확인하지 않았다. 카카오 SDK 키와 계좌·RSVP 백엔드는 별도 배포 설정이 필요하다.
