# 사진과 여백 중심의 디자인 시안

검토 브랜치: `codex/impeccable-hallmark-design`. 사용자 확인 후에만 `main`에 병합한다.

## 방향과 참고 자료

기존의 밝은 아이보리·옅은 초록색과 한글 명조체를 유지하면서, 인쇄된 사진 청첩장처럼 사진과 이름에 시선을 모은다. 꽃잎, 사진 가장자리 마스크, 새 장식 효과는 추가하지 않는다.

- [Impeccable의 craft floor](https://github.com/pbakaus/impeccable/blob/main/skill/reference/craft-floor.md): 반복되는 영문 소제목을 줄이고, 제목·본문의 위계와 여백을 정리한다. 모션은 오프닝에 집중하고 대비·초점·작은 화면을 검증한다.
- [Hallmark의 redesign 지침](https://github.com/Nutlope/hallmark/blob/main/skills/hallmark/references/redesign.md), [craft 지침](https://github.com/Nutlope/hallmark/blob/main/skills/hallmark/references/craft.md): 실제 사진을 중심으로 구성하고, 불필요한 카드와 아이콘 배경을 줄인다. 콘텐츠와 기존 동작을 보존한다.

두 프로젝트의 디자인 원칙을 참고한다. CLI, 테마, 외부 훅, 텔레메트리는 설치하지 않는다. 해당 도구의 전체 감사 절차를 실행했다는 의미는 아니다.

## 구현과 검증 계획

1. 표지의 이름·사진·일정 순서를 재구성한다. `Cover`의 오프닝과 다음 섹션 이동은 유지한다. 390px와 320px 화면에서 사진, 일정, 이동 버튼을 확인한다.
2. `Section`, `Button`, 인사말·가족·달력·갤러리·오시는 길·계좌·참석·공유의 표현을 정리한다. 초대 문구는 가운데, 정보는 왼쪽으로 정렬한다. 가족 2열, 갤러리 5장/더보기, 날짜 강조, 지도 링크, 입력·접기 기능을 확인한다.
3. 빌드, 린트, 기존 테스트를 실행하고 브라우저 화면을 검토한다. 큰 글자 모드와 가로 넘침을 확인하고 변경 전후 화면을 남긴다.
4. `.claude/skills/lean-comments`와 `git-commit` 규칙에 따라 변경분만 커밋한다. 시안은 별도 브랜치에서 검토한다.

## 보존 범위

이름, 부모님 성함, 2027년 6월 27일 오후 1시, 노블발렌티 삼성과 교통 정보, `gallery/04.webp` 표지, 갤러리 순서, 섹션 ID, 링크, 폼 검증 및 전송 경로를 유지한다. 네이버 지도 연동은 보류하며 현재 대체 표시와 외부 링크를 유지한다.

## 검증 결과

- 빌드와 린트 통과. 기존 테스트 20개 파일, 153개 항목 통과.
- 실제 브라우저 CSS 뷰포트 390×844 및 320×568에서 가로 넘침 없음. 320px 큰 글자 모드에서도 이름이 한 줄에 표시되고 표지 이동 버튼이 첫 화면 안에 들어온다.
- 오프닝 종료 후 표지 표시, 표지에서 인사말로 이동, 가족 2열, 사진 5장/10장 확장·접기, 사진 확대·다음 사진·닫기, 계좌 펼침·접기, 참석 폼의 빈 이름 오류와 초점 이동 확인.
- 변경 전후 섹션 ID, 외부 링크, 입력 필드 구성이 일치한다. 새 의존성이나 전송 경로는 없다.
- 화면 기록은 로컬 `qa/editorial-design/`에 저장한다. 실제 휴대폰의 인앱 브라우저, 지도 SDK, 메시지 실전송은 검증하지 않았다. 모션 감소 설정의 기존 코드 경로는 유지하며 OS 설정 전환 테스트는 하지 않았다.
